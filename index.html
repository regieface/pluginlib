Données…

Les données sont collectées automatiquement chaque nuit sur les sites des constructeurs (pages produit, boutiques, sitemaps). Un lien n'est affiché que si la page a répondu correctement lors de la dernière collecte. Les latences proviennent du tableau officiel Waves ; les autres constructeurs ne publient pas de tableau équivalent.

La catégorie et les critères (FET, VCA, dynamique, side-chain…) sont déduits automatiquement des mots employés par le constructeur : ils peuvent être incomplets. Corrections possibles dans data/overrides.json.
